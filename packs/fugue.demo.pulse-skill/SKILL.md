# Pulse Study

Use this skill when a Fugue sketch needs a simple rhythmic idea with a clear
musical arc. Follow the [pulse rules](policies/fugue.demo.pulse-policy.md)
throughout.

1. Start with one steady pulse and a restrained sound.
2. Establish repetition before adding variation.
3. Vary the pulse in timing, pitch, articulation, or timbre.
4. Return to the opening idea or end with an intentional release.
